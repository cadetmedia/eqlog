EQLog is a backup-first EverQuest Legends log cleaner with a simple
charcoal-and-gold desktop interface.

## Download and install

Download **eqlog-Setup-0.1.0.exe** from the assets below and double-click it.
Requires Windows 10/11 **64-bit**. No separate Python installation or
administrator access is needed. The installer adds Desktop and Start menu
shortcuts and a Windows Apps uninstall entry. This release is unsigned.

## Use EQLog

1. Close EverQuest Legends and EverQuest Companion.
2. Open EQLog and click **OK** to confirm both apps are closed.
3. Browse to the character log in EverQuest's `Logs` folder.
4. Click **Analyze log** to preview the savings.
5. Click **Back up & clean**, wait for completion, then reopen the other apps.

The first cleanup preserves the full original log in a sibling
`.original-backup.txt.bak` file. Later cleanups add only new log data, preserving
history removed from the working log. Keep the backup and `.eqlog-state.json`
tracking file together. Cleanup stops if it cannot verify a safe append boundary.
Uninstall removes application files and shortcuts while preserving user backups.

The conservative filter removes ordinary chat and blank lines while retaining
pet/group evidence, gameplay messages, unknown messages, and timestamp anchors.
Custom alerts or searches that depend on removed chat will lose that input.
Size reduction depends on the log; combat-heavy logs may shrink very little.

Windows build, packaged-runtime, cumulative-backup, and install/uninstall checks
must pass before this workflow publishes the installer. The accompanying
`.sha256` asset contains the installer's SHA-256 checksum.
